# Unideva Suit Ailesi (Üretim)

**Unideva Suit**, üretim yapan işletmeler için reçete, MİP (malzeme ihtiyaç planlama), lot/fire takibi, iş emri, fason ve kalite kontrol süreçlerini yöneten üretim paket ailesidir. Suit paketleri, Elite-L seviyesinde ön muhasebe kapsamını içerir.

## Kapsam Kademeleri

- **Suit-S:** reçete, MİP, lot/fire takibi
- **Suit-M:** + iş emri, rota/safha yönetimi
- **Suit-L:** + fason üretim, kalite kontrol, makine/personel takibi
- **Suit-Prime:** + Prime'ın genel muhasebe/beyanname modülleri

- e-Fatura / e-Arşiv + e-İrsaliye + e-Müstahsil + e-SMM + e-Ticaret (1 pazaryeri)

- **e-Defter yalnız Suit-Prime paketinde** dahildir (1 VKN + 500 e-SMM makbuzu + 1.000 kontör + 100 MB e-Defter saklama)
