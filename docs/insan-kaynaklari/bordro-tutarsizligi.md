# Bordro Tutarsızlığı

## Sorun

31 gün olan aylarda personel bordrolarında maaş tutarı ve çalışma günü hatalı görünüyor.

## Çözüm

1. İlgili personelin kartını açın.
2. **"Otuz günden az"** alanının işaretli olup olmadığını kontrol edin.
3. Eğer yanlışlıkla kısıtlanmışsa (işaretlenmişse) düzeltme yapın.
4. Düzeltmeden sonra bordroyu yeniden oluşturun.
